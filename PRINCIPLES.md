# Principles

## What I value

- Simple, minimal systems.
- Clean code and intuitive concepts.
- Real patterns over speculative abstractions.
- Useful defaults over sprawling configuration.
- Honest failures over hidden recovery.

## How I think

- Think deeply, then compress the result into something simple.
- Start with the concrete problem before reaching for a general solution.
- Explore trade-offs instead of treating design choices as universal rules.
- Prefer designs that are easy to explain and difficult to misuse.
- Treat programming paradigms as tools, not identities.
