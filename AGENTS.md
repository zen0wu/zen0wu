# Required guidance

For every software engineering task, read `PRINCIPLES.md` and `ENGINEERING.md` from the directory containing this file in full before substantive work. Treat both files as instructions, not optional reference material.

Software engineering tasks include investigation, explanation, design, implementation, debugging, testing, refactoring, code review, migration, release, and incident response.

`PRINCIPLES.md` describes how to evaluate designs and code. `ENGINEERING.md` describes how to take work from an initial request through verification and handoff.

Repository-specific instructions add local facts and constraints. Follow them without silently replacing the principles or engineering practice defined here.
